Windmill's own API

Identify an unbound stream

Night Mode and Beeping Mode are named by the export API but sit at 0 on every unit here, so correlating values cannot bind them. Instead: start watching, toggle the feature in the Windmill app, and whichever pin moves is the one. Nothing is ever written to an unidentified pin.

Add an AC unit

Windmill app → the unit → its auth token. It is stored here and never shown again — the dashboard only ever displays its last four characters.

Defaults

These are stored with the unit itself, so nothing the unit reports can overwrite them — this dialog is the only place they change. Anything left as “system default” follows the settings on this tab; anything left as “leave alone” is not held at all. With the last box ticked, a unit that wanders off these is set back — up to four times an hour, then it gives up and says so in the log. A change you make in Controls outranks the default for four hours, so you can put a unit on fan for the afternoon without editing anything here. Eco is the exception: these units drop into it by themselves and after most writes, so it is barred rather than merely corrected — taken back out every time, unless you picked it.
